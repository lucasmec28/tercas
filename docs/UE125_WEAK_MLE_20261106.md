# Ue125 restricted weak LOCAL MLE components

Scope: public nominal Ue125×50×17×2, ri=2, index26 and the existing pinned rounded
contour/material (E200000,G77000,fy300,fu400). Synthetic section-only work; no
private loads or project data. This isolated module is not called by production.
It does not change input properties, global CG/Iy, demands or ELS.

`ue_catalog_nbr_weak_mle.qualify(data)` returns LOCAL capacities separately:
- positive My_app, web compressed: approximately1.351021886640 kN·m;
- negative My_app, lips compressed: approximately1.371904199652 kN·m.

These are not complete bending resistances. No Me, D, §9.9, combined stress,
primary torsion, high-rotation validity or whole-member approval is qualified.
`MRd_Nmm` is deliberately absent. Data without an explicit own-contour marker
return None; edited or other contour/material markers fail closed. Historical
inputs/results are not rewritten or automatically adopted.

## Method and sources

NBR14762:2010 §§9.2.2,9.2.3,9.8.2.1(a). The publisher-authored
[CBCA Steel Framing: Engenharia2016](https://www.skylightestruturas.com.br/downloads/101497_manual_lsf_engenharia_2016.pdf)
explains tension-first iteration (p61), uniform AA web k4 and equal edge strips
(Table4.2(a),p62), stiffeners (pp64–65), first-yield Wef (p73), and flat widths
excluding bends (p113). The table was checked visually.

All bends remain in the original faceted midsurface section. Flat widths are
web117, flange42, lip13mm. A conservative uniform300MPa compression envelope
proves the flanges and lips fully effective: Is366.1667≥Ia_upper186.5784mm4,
kflange3.2261905, lambda_flange.4766464 and lambda_lip.4041114<.673.
Tension portions are fully effective. This proof covers every local iteration
because the maximum absolute exterior stress is normalized to fy.

For positive My, reduce only the uniform AA web at x=0, retaining two strips
bef/2 next to its supported edges, y=3 and120mm. Put S=A·CGx and
Q=Iy+A·CGx², using the pinned gross section. Removing the central web strip
leaves S and Q unchanged. For effective web width w:

- Aef=A−t(117−w); CGef=S/Aef; Iyef=Q−S²/Aef.
- Exterior fibre distances: cweb=CGef+1 and clips=49−CGef.
- sigma_web=fy·cweb/max(cweb,clips).
- lambda=117/(2·.95)·sqrt(sigma_web/(4E)); rho=1 below.673,
  otherwise(1−.22/lambda)/lambda.
- Solve w=117rho and use Wfirst=Iyef/max(cweb,clips).

The bracket[80.014153602497,117] follows from sigma≤300MPa. Within it,
CGef≤17.793314<24mm, so first yield remains on the tension lips. The fixed-point
derivative has upper bound.305658<1, giving a unique root. Production uses64
bisections and the lower endpoint (conservative), checking residual and bracket.
The dimensions are not snapped to a more favourable gross section.

Exterior web stress is a conservative majorant of midsurface stress. Its extra
reduction does not create a favourable modulus here: both
Wlip=(Q Aef−S²)/(49Aef−S) and Wweb=(Q Aef−S²)/(Aef+S) increase with Aef.
Their derivative signs are positive: S(49S−Q)>0 and S(Q+S)>0, respectively.
This is specific to web-only reduction in this pinned section, not a universal
MLE monotonicity claim. Corners use the existing line-section convention, not
a newly introduced through-thickness inertia correction.

At convergence: bef101.080990500237mm, Aef459.857308011667mm²,
CGef16.163030833208mm, Iyef162666.034795986mm⁴,
sigma_web156.802207408640MPa, Wfirst4953.746917681mm³.

## Optional FLT effective-section arithmetic

`flt_effective_section(data, sign, chi)` evaluates Wc,ef at sigma=chi·fy,
0<chi≤1. Positive/web compression needs direct web reduction at that specified
stress; negative/lips compression stays fully effective. It DOES NOT qualify
chi, Me or an FLT resistance and exposes no MRd_FLT denominator.

A later consumer must calculate chi·fy·Wc,ef/gamma and retain the minimum with
LOCAL first-yield capacity and any applicable D resistance. The local cap is
essential when tension yields first. Do not copy Wef(fy) into this helper.
The AnnexE j, r0, Nex and Nez must come from this same contour and verified
lengths; never copy them from Ue100. This change supplies none of those values.
No automatic D exemption is inferred for either sign, including from AISI F4.
