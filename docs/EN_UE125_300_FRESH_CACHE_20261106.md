# Avoid duplicate replay of an internally generated EN300 proof

The public calculate function already authenticated the original normal and shear snapshots, the complete pinned section and the source field (K*u−f, recovered coefficients, critical states and numerical diagnostics), then computed every sufficient bound. The first saved-read call in complete_result repeated this work unnecessarily.

The implementation now separates the side-effect-free internal _calculate from the public fresh-generation wrapper. Only a successful fresh generation derives its own compact summary and registers the full canonical cache token. A caller cannot submit a saved candidate for registration through this wrapper. Token construction is shared with the saved reader and includes the entire proof/dense demand, summary, original normal snapshot, source hash and origin; native finite JSON types are required. Normal, shear and section authorities remain checked before every hit.

A cold external snapshot still executes the complete internal calculation/replay. It is registered only after its whole canonical contents equal the independently replayed result. A failed candidate registers neither itself nor the expected result. Returned-object mutation changes the key and cannot inherit the earlier cache entry.

No output field, schema, resistance, stress operator, Bernstein bound, action, stiffness, solver, guard or tolerance changes. No stress-bound refinement was implemented.
