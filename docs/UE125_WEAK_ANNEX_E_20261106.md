# Own Ue125 Annex E reference components

Standalone, not wired to production. This module depends on the separately
qualified weak LOCAL MLE component. It does not touch the frozen release,
consumers, saved projects, action geometry or global section properties.

## Reference domain, not actual-action applicability

The explicitly selected roof model must be one physical span L, fork ends,
free warping, no intermediate restraints. Use Nex=pi² E Ix/L² and
Nez=(GJ+pi² E Cw/L²)/r0², with Lx=Lz=L and Cm=1. Manual segment lengths,
weak_catalog Lx, supplied criticals and favourable moment-gradient factors are
never treated as new supports. Reference axial force is zero and bending is
pure weak-axis. The support idealization is not verification of a real connection.

The capacity is a SHEAR-CENTER reference. `qualify_reference` sets actual-load
applicability to not_assessed, even when a load line is selected. No real
combination is released by this module.

The existing `roof_biaxial.classify` checks the parallel load contribution
Fparallel*(xload−xSC) for EVERY individual action. Positive is stabilizing, zero
neutral; negative or unknown remains pending. It must not classify only the net
resultant, moment sign or sum of contributions. Its position evidence must first
be verified against the pinned geometry. Positive force at the usual web or
flange-midwidth location is stabilizing, but that statement alone is not a
certificate for all actions or combinations. Strong-axis load height remains in
its separate model, and primary torsion/bimoment/high rotation remain outside
this reference. No favourable position benefit is included here.

## Own-contour j, signs and controls

NBR14762:2010 Annex E.1–E.2.1, printed pp82–83, defines x along the symmetry
axis with the shear center on its negative side; x0 in the expression is a
positive distance. Coordinates in the cubic integrals are relative to gross CG:

j=(integral(x³ dA)+integral(x y² dA))/(2 Iy)+x0.

The 134-node contour generated by the existing nominal_channel_nodes function
(h125,bf50,lip17,t2,ri2,32 facets per bend) has exactly the existing pinned hash
3814f4cd9fcfa474b6e3fcbd21eedb3fdee38818eca0440abb4408fd506143e2.
Each straight segment has affine x(u),y(u), so cubic integration is exact for the
faceted midsurface with dA=t ds. This is not a new thin-wall member eigensolve.

- integral x³ dA =2371211.9640796753mm⁵.
- integral x y² dA =7479744.204188343mm⁵.
- CGx=15.116450045292856mm, SCx=−23.516981965583753mm.
- x0=38.63343201087661mm, j=67.53119802572517mm.
- r0²=(Ix+Iy)/A+x0²=4241.6685274439105mm².

Independent two-point Gauss integration reproduces the cubic integrals.
Separate scalar sectorial primitives and orthogonality reproduce SC and
Cw569368182.448454mm⁶ without calling from_polyline or any linear/eigen solver.
No Ue100, sharp-corner j or catalogue r0 was copied.

Cs=+1 for positive My_app, web compression; Cs=−1 for negative My_app,
lip compression. Physical Vlasov My uses the opposite sign. Evaluate Me+ by
Nex*(sqrt(j²+r0² Nez/Nex)+j). Evaluate Me− by the equivalent rationalized
r0² Nez/(sqrt(j²+r0² Nez/Nex)+j), avoiding cancellation.

Synthetic L5000mm gives Nex93270.73746624N, Nez22499.69071770N,
Me+=13268249.60458197Nmm, Me−=670880.32090602Nmm. Independent55-digit
Decimal arithmetic verifies both roots. Their product is Nex*Nez*r0² and
their difference is2*Nex*j. Different lengths are tested. Nonpositive,
nonfinite or numerically unrepresentable spans fail closed; no fictitious
normative minimum/maximum length is introduced.

## NBR curve and protected first yield

For each sense, compute lambda0=sqrt(Wc,gross*fy/Me), the existing NBR chiFLT
curve, then Wc,ef at chiFLT*fy using the restricted MLE helper. The reference
FLT component is chiFLT*fy*Wc,ef/1.1. It is NOT based on Wef at the local
first-yield state. Preserve min(local-first-yield, FLT-reference); this local cap
is essential for web compression where the tension lips yield first.

The resulting local/FLT minimum still lacks applicable distortional resistance
and actual-action applicability. It is NOT `MRd_Nmm`, not a denominator for
§9.9, and not approval. No distorcional exemption is inferred in either sense.
The calculation neither imports AISI resistance nor uses a roof-sheet restraint.
